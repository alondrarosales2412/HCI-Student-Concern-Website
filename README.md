Canvas Feedback Portal
Project documentation and front-end design for Human-Computer Interface (HCI).

(Project Overview)
The Canvas Feedback Portal is a user-centric web interface designed to streamline how students report technical issues and provide feedback on their learning management system. This project bridges the gap between student frustrations and IT support resolution by providing a clear, accessible communication channel.

(My Technical Contributions)
While this was a collaborative effort, my specific technical and administrative focuses included:

FAQ Development: I personally built the Frequently Asked Questions (FAQ) section using HTML and CSS. I focused on creating an organized, easy-to-navigate layout to help users find instant solutions to common Canvas glitches.

Front-End Styling: Assisted in the overall CSS layout to ensure the site was responsive and professional.

Project Documentation: Led the creation of the Project Proposal and the Final Technical Report, ensuring all project goals met the requirements for student accessibility.

(Key Features)
Technical Support Survey: A structured form for reporting bugs and suggesting new features.

Self-Service Resources: A dedicated FAQ section to reduce the volume of repeat support tickets.

User-First Navigation: Simplified headers and clear call-to-action buttons like "Go to Survey."

(Tech Stack)
HTML5: Semantic page structure.

CSS3: Custom branding, layout, and UI styling.
